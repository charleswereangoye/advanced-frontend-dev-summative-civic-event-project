# CivicEvents+ Video Demonstration

This directory contains the official video demonstration link and submission details for the **CivicEvents+** accessible city events and services portal.

---

[![CivicEvents+ Video Demonstration](https://img.youtube.com/vi/1M6YVRDBgYQ/hqdefault.jpg)](https://youtu.be/1M6YVRDBgYQ)

- **Video URL:** [https://youtu.be/1M6YVRDBgYQ](https://youtu.be/1M6YVRDBgYQ)
- **Duration:** ~5–7 minutes
- **Resolution:** 1080p Full HD
- **Audio:** Clear voiceover commentary explaining frontend features, accessibility, and Role-Based Access Control (RBAC).

---

## Demonstration Highlights
- **Architecture & Design:** Pure semantic HTML5, Tailwind CSS, and jQuery 3.7.1 with responsive layouts and WCAG AA contrast.
- **Resident Experience:** User authentication, dynamic event search & filtering, event registration, 5-star feedback, audio announcements with custom player, and video promos with WebVTT closed captions.
- **Admin Dashboard:** Platform analytics metrics, 6-month growth charts, citizen status management, event creation, and registered attendee rosters.
